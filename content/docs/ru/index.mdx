# Добро пожаловать в OBScure

OBScure — это десктопное приложение для Windows (на Electron), которое служит панелью управления трансляцией. Оно заменяет собой набор разрозненных браузер-оверлеев, виджетов алертов и ботов для мини-игр одним приложением, которое:

- раздаёт **оверлеи** — веб-страницы, которые вы добавляете в OBS как Browser Source — собранные визуально в узловом редакторе **Scene Builder**, без единой строчки HTML/CSS/JS,
- подключается к **Twitch, YouTube, Spotify, Streamer.bot, самому OBS и медиа-сессии Windows**, чтобы получать живые алерты, чат, данные «сейчас играет» и статистику,
- включает две встроенные интерактивные игры для стрима, **Random** и **Roulette**, с честной проверкой результата через хэш и seed,
- содержит переиспользуемую систему **Действия и очереди** (по образцу Streamer.bot), которая запускает именованные сцены по команде в чате или внешнему триггеру,
- и организует всё это в **профили** — отдельные наборы оверлеев, интеграций и настроек, между которыми можно переключаться мгновенно.

Всё, что OBScure отдаёт в OBS, — это один локальный веб-сервер, работающий на вашем же компьютере: ничего не уходит наружу, кроме обращений к API, которые нужны самим интеграциям (Twitch, YouTube, Spotify).
