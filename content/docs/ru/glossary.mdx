# Глоссарий

- **Оверлей (Overlay)** — веб-страница, которую раздаёт OBScure, предназначенная для добавления в OBS как Browser Source. Собирается визуально как *сцена* в Scene Builder.
- **Сцена (Scene)** — один граф нод в Scene Builder; превращается ровно в одну страницу оверлея. Также название обязательного итогового узла, который есть у каждой сцены.
- **Узловой редактор / Scene Builder** — визуальный, основанный на нодах интерфейс для сборки сцены. См. [«Scene Builder»](/ru/docs/scene-builder).
- **Нода (Node)** — один визуальный строительный блок графа сцены — контент (Text, Image...), модификатор (Position, Opacity...), шаг процесса (Task, Wait...) либо источник живых данных (Event, Variable...).
- **Сокет (Socket)** — подписанная точка подключения на ноде. Входные сокеты группируются по *роли* (Transform, Style), а не по одному на тип ноды; цвет обозначает вид (content/style/data/process).
- **Связь данных/композиции** — провод «передаёт в», определяющий, что существует и как оно вложено, направленный к Scene.
- **Связь последовательности** — провод «затем» в цепочке `Start → Task → Wait → End`, определяющий, *когда* что-то происходит.
- **Процесс (Process)** — цепочка Start→Task→Wait→...→End для пошаговой, точно рассчитанной по времени последовательности. См. [«Ноды процесса»](/ru/docs/scene-builder/process-nodes).
- **Сцена по событию** — более простой паттерн `Event (+ Timer) → Scene`: показывается на фиксированное окно времени при срабатывании алерта, без многошагового тайминга.
- **URL-ключ** — слаг, задающий адрес оверлея сцены (`/overlays/<urlKey>.html`) на локальном overlay-сервере.
- **Overlay-сервер** — локальный HTTP/WebSocket-сервер, встроенный в OBScure, который раздаёт все страницы оверлеев и отправляет в них обновления в реальном времени.
- **Интеграция (Integration)** — подключение к внешнему сервису (Twitch, YouTube, Spotify, Streamer.bot, OBS, Windows Media). См. [«Интеграции»](/ru/docs/integrations).
- **Алерт (Alert)** — уведомление в реальном времени от подключённой платформы (фоллов на Twitch, членство на YouTube...), сопоставляемое [нодой Event](/ru/docs/scene-builder/live-data-nodes#event).
- **Команда (Command)** — зарегистрированное слово-триггер чата (с необязательным префиксом и уровнем прав), общее для входа в Рулетку, Действий и нод Event. См. [«Команды»](/ru/docs/actions-and-queues#commands).
- **Действие (Action)** — именованный триггер, запускающий одну сцену и попадающий в очередь. См. [«Действия и очереди»](/ru/docs/actions-and-queues).
- **Очередь (Queue)** — куда попадают запуски Действия; блокирующая выполняет их по одному, обычная — все параллельно.
- **Переменная (Variable)** — именованное типизированное значение, используемое как плейсхолдер шаблона `{name}` — локальное для одной ноды, общее глобально либо читаемое вживую из подключённой интеграции. См. [«Нода Variable»](/ru/docs/scene-builder/live-data-nodes#variable).
- **Плейсхолдер (Placeholder)** — синтаксис `{слово}` в содержимом ноды Text, подставляемый при рендере живым значением (поле алерта, Variable, время, текущий трек...).
- **Профиль (Profile)** — изолированный, переключаемый набор оверлеев, токенов интеграций и настроек. См. [«Начало работы → Профили»](/ru/docs/getting-started#профили).
- **Честно проверяемо (Provably fair)** — гарантия Random и Roulette: хэш результата публикуется до того, как кто-либо мог на него повлиять, а seed раскрывается только после, так что любой может независимо проверить результат. См. [«Инструменты»](/ru/docs/tools).
