# Проигрыватель Windows

Показывает текущий трек из любого плеера, запущенного на компьютере, — десктопного приложения Spotify, вкладки браузера, VLC и т.д. — считывая системные медиа-элементы управления Windows (SMTC). Авторизация не нужна, отдельный аккаунт подключать не требуется.

## Включение

Просто включите **«Включить интеграцию»**. Больше никаких полей нет — пока интеграция включена, OBScure опрашивает системную медиа-сессию каждые несколько секунд.

Только для Windows: на других платформах эта интеграция ничего не делает.

## Что становится доступно после подключения

Данные ровно той же формы, что и у [Spotify](/ru/docs/integrations/spotify) — подключайте так же через [ноду Audio Player](/ru/docs/scene-builder/live-data-nodes#audio-player) для `{artist}`/`{title}`/обложки альбома и события смены трека. Используйте эту интеграцию вместо Spotify (или вместе с ней), если хотите, чтобы «сейчас играет» отражал *всё, что реально звучит* на компьютере, а не только Spotify.
