# Инструменты

OBScure включает две игры для трансляции в разделе **«Инструменты»** боковой панели. Обе честно проверяемы: хэш публикуется *до* того, как кто-либо мог повлиять на результат или предсказать его, а seed, лежащий в его основе, раскрывается только потом, — так что любой может независимо пересчитать результат и убедиться, что он не был подменён.

Эта страница — про настройку и запуск игр из приложения. Чтобы реально **вывести** выпадающие числа или крутящееся колесо на оверлей, см. [справочник нод «Инструменты»](/ru/docs/scene-builder/tools-nodes) — размещение ноды Random или Roulette в Scene Builder выводит ровно то живое состояние, что описано здесь.

## Random  [#random]

Генератор случайного числа с хэшем, показанным под ним.

- **Диапазон** — **От** / **До**.
- **Количество** — сколько чисел сгенерировать за раз.
- **Сгенерировать** — сразу публикует хэш (фаза: хэш опубликован, ожидание).
- **Показать результат** — раскрывает seed и сами числа.

**Как проверить**: `число = min + (первые 4 байта SHA-256(seed + ":" + индекс)) % (max − min + 1)`, где `индекс` начинается с 0 для каждого сгенерированного числа. Поскольку хэш публикуется до раскрытия, любой может пересчитать его сам, как только seed станет известен.

Раскрытый результат остаётся на экране бессрочно — автоматического таймера очистки нет, поскольку иначе объявленное число могло бы пропасть из вида, пока кто-то его ещё читает. Запустите заново (**«Новый раунд»**), когда будете готовы к следующему.

## Roulette  [#roulette]

Колесо с таймером; зрители присоединяются командой в чате или редимпом награды за баллы канала.

- **Команда в чате** — выбирается из общего [реестра команд](/ru/docs/actions-and-queues#commands).
- **Награда за баллы** — награда за баллы канала Twitch (требует подключённого [Twitch](/ru/docs/integrations/twitch); список подтягивается вживую с вашего канала). Каждый повторный редимп даёт зрителю ещё один билет, пропорционально увеличивая его шансы.
- **Приём участников** — сколько времени открыт приём, в секундах/минутах/часах/днях/неделях.
- И команда в чате, и награда за баллы ограничены типами зрителей (Все/Фолловеры/Сабскрайберы), разрешёнными для этой команды на странице «Команды».
- **Добавить вручную** — добавить участника по имени без чата и баллов вообще.

Жизненный цикл раунда: **«Начать раунд»** открывает приём на настроенное время; **«Начать досрочно»** завершает приём раньше и сразу выбирает победителя; **«Отменить раунд»** прерывает раунд без выбора победителя.

**Как проверить**: `SHA-256(seed)` публикуется в момент старта раунда, до того как кто-либо мог войти. После закрытия приёма seed раскрывается, и `roll = parseInt(SHA-256(seed).slice(0, 8), 16) % totalWeight` — победитель — первый по порядку входа участник, у которого накопленная сумма весов превышает `roll`.
