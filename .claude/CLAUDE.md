# Project Rules

## Authorship

- **No AI co-authorship**: Do not add any AI-generated attribution comments, co-authored-by lines, or similar annotations to any file, commit message, or pull request. All code is authored solely by the project contributors.
- Do not insert comments like `// Generated by ...`, `# Co-authored-by: ...`, or any equivalent.

## Code Style

- TypeScript strict mode always on.
- Use shadcn/ui components exclusively for UI primitives вЂ” do not install other UI libraries.
- All new pages and layouts use Next.js App Router conventions.
- Keep fumadocs content under `content/docs/`.
- Local knowledge base lives in `docs/` (git-ignored, local only).
