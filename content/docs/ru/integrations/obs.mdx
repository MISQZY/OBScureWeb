# OBS

Подключается к встроенному WebSocket-серверу OBS — читает уровни звука в реальном времени с аудио-микшера OBS для ноды [Equalizer](/ru/docs/scene-builder/content-nodes#equalizer).

## Подключение

1. В OBS откройте **Инструменты → Настройки WebSocket-сервера** и включите сервер.
2. В OBScure укажите те же **Host** и **Порт**, что показаны в этом окне.
3. Указывайте **Пароль**, только если в том же окне OBS включена галочка **«Enable Authentication»**.
4. Нажмите **«Подключить»**.

## Что становится доступно после подключения

- Текущие входы аудио-микшера OBS (Desktop Audio, Mic/Aux и т.д.) становятся доступны для выбора в [ноде Audio Source](/ru/docs/scene-builder/live-data-nodes#audio-source) (Source = OBS) — выберите нужный там, а затем подключите эту Audio Source к сокету Source ноды Equalizer.

## Заметки

- obs-websocket отдаёт только один уровень пик/амплитуда на вход, а не настоящий частотный спектр — Equalizer, работающий от источника OBS, показывает *синтезированный* псевдоспектр, реагирующий на реальную громкость, а не честный частотный анализ. Для настоящего спектра используйте реальный микрофон/устройство в ноде Audio Source (Source = «Микрофон/устройство») — в этом случае анализ делает сам OBScure.
