# Ноды инструментов

Random и Roulette — не самодостаточные ноды: размещение любой из них лишь выводит на сцену **живое состояние** соответствующего инструмента уровня приложения. Реальные настройки (диапазон, количество, команда входа, награда за баллы, длительность...) находятся на странице настроек этого инструмента в разделе **«Инструменты»** боковой панели — см. [«Инструменты»](/ru/docs/tools) про их настройку. Эта страница — про то, как их *отобразить* на оверлее.

Размещение ноды Random или Roulette из палитры автоматически создаёт и жёстко связывает с ней соответствующий виджет отображения — сам виджет отдельно никогда не добавляется.

## Random  [#random]

Нода данных/управления. Два выхода:

- **Content** — подключите к сокету Source собственного связанного **Random Widget** (постоянная связь) либо к сокету Content любой ноды контента, чтобы заполнить плейсхолдеры `{number}`/`{numbers}`/`{hash}`/`{seed}` в существующем шаблоне.
- **Event** — сигнал фазы розыгрыша. Подключите к сокету Event у Start в процессе, чтобы запускать его в момент **фиксации** розыгрыша (хэш опубликован, числа ещё не известны), и/или к сокету Visibility связанного Random Widget, чтобы скрывать конкретно этот виджет вне активного розыгрыша.

### Random Widget  [#random-widget]

Реально отображаемые выпадающие числа — в остальном обычная нода контента (те же сокеты Transform/Style и выходы Content/As Target, что у Text/Image), поэтому её можно позиционировать, масштабировать, анимировать или передать в Task, как любую из них. По умолчанию показывается безусловно; подключите собственный выход Event связанного Random к её необязательному сокету **Visibility**, чтобы вместо этого скрывать её вне активного розыгрыша. У неё есть собственный сокет **Layout** (Ordering) для расстановки нескольких выпавших чисел относительно друг друга, когда Count больше 1.

Отдельно удалить нельзя — удаление ноды Random, с которой она связана, удаляет и её.

## Roulette  [#roulette]

Нода данных/управления. Два выхода:

- **Content** — передаёт данные в собственный связанный Roulette Widget и (опционально) в список Roulette Entrants через их общий сокет Source; больше ни для чего не используется.
- **Event** — сигнал фазы раунда. Подключите к сокету Event у Start в процессе, чтобы запускать его в момент начала сбора участников, и/или к сокету Visibility связанного Roulette Widget, чтобы скрывать конкретно этот виджет вне активного раунда.

### Roulette Widget  [#roulette-widget]

Само крутящееся колесо — та же форма обычной ноды контента (Transform/Style/Content/As Target), позиционируется/анимируется/может быть целью Task, как любой другой контент. По умолчанию показывается безусловно; подключите выход Event связанного Roulette к её необязательному сокету **Visibility**, чтобы вместо этого скрывать её вне активного раунда. Отдельно удалить нельзя.

### Roulette Entrants  [#roulette-entrants]

Обычная, **необязательная**, свободно удаляемая нода данных, форматирующая список участников связанной рулетки в строки — в отличие от Widget, её удаление не затрагивает саму Roulette или её Widget.

- **Row template** — форматирует каждого участника, используя токены `{name}`, `{chance}` (взвешенный шанс победы, 0–100%), `{weight}` (число билетов).
- **Layout** — List (по одной строке) или Inline (объединены в одну строку через **Separator**, например «Alice, Bob, Carla»).
- **Sort by chance**.

Подключите её собственный выход Content к сокету Content ноды Text, чтобы полностью *заменить* шаблон этой Text отформатированными строками (текстовое поле станет доступно только для чтения при подключении) — Color/Size/Font/Align и все остальные поля оформления остаются собственными полями этой Text.
