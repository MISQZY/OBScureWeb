# Twitch

Отслеживает подписки, рейды и фолловы на вашем канале, читает чат, следит за редимпами баллов канала и передаёт статистику Twitch (фолловеры/подписчики/зрители, статус эфира, категория, время в эфире) на Дашборд и в [переменные со scope=integration](/ru/docs/scene-builder/live-data-nodes#variable).

## Подключение

По умолчанию используется встроенный Client ID — в большинстве случаев достаточно нажать **«Подключить»** и подтвердить доступ в открывшемся браузере. Шаги ниже нужны только если вы хотите использовать своё собственное Twitch-приложение:

1. Откройте [Twitch Developer Console](https://dev.twitch.tv/console/apps) и зарегистрируйте приложение.
2. Укажите в приложении **OAuth Redirect URL** ровно `http://localhost:47891/callback/twitch`.
3. Скопируйте **Client ID** приложения в поле Client ID на этой странице.
4. Нажмите **«Подключить»**.

Twitch использует flow **Device Code Grant** — единственный OAuth-flow Twitch, не требующий client secret, поэтому десктопное приложение вообще может поставляться с безопасным Client ID по умолчанию. OBScure открывает собственную страницу подтверждения Twitch в браузере; после подтверждения там приложение самостоятельно завершает обмен токенами.

## Что становится доступно после подключения

- Типы алертов **ноды Event**: `subscription`, `raid`, `follow` — см. [«Ноды живых данных»](/ru/docs/scene-builder/live-data-nodes#event).
- **Редимпы баллов канала** — сверяются с [настройками входа в Рулетку](/ru/docs/tools#roulette) и триггерами команд чата в [Действиях](/ru/docs/actions-and-queues).
- **Чат** — читается для команд чата, запускающих [команды](/ru/docs/actions-and-queues#commands) (вход в Рулетку, Действия).
- **Статистика в реальном времени** — фолловеры, подписчики, зрители, статус эфира/категория/время в эфире, отображается на Дашборде и через [ноду Variable](/ru/docs/scene-builder/live-data-nodes#variable) со Scope = Integration.

## Заметки

- Запускайте **только один экземпляр** OBScure одновременно. Twitch обновляет refresh-токен при каждом использовании — если второй (например, оставшийся висеть) экземпляр тоже держит сессию и позже сохраняет свою конфигурацию на диск, он может перезаписать рабочий токен устаревшим и незаметно сломать подключение до следующего переподключения.
- Редимпы засчитываются, только пока награда действительно включена и видна в панели трансляции (Creator Dashboard).
