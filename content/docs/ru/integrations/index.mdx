# Интеграции

На странице каждой интеграции есть значок статуса подключения (**«Подключено»**, **«Подключение...»**, **«Не подключено»**, **«Ошибка»**) и собственные поля настройки. После подключения данные сервиса становятся доступны по всему приложению — как триггер [ноды Event](/ru/docs/scene-builder/live-data-nodes#event), [переменная со scope=integration](/ru/docs/scene-builder/live-data-nodes#variable), карточка на Дашборде или источник триггера в Действиях и очередях.

| Интеграция | Для чего нужна | Авторизация |
|---|---|---|
| [Twitch](/ru/docs/integrations/twitch) | Подписки, рейды, фолловы, баллы канала, чат, статистика в реальном времени | OAuth device-code (без client secret) |
| [YouTube](/ru/docs/integrations/youtube) | Членства, Super Chat | Google OAuth (Client ID + Secret) |
| [Spotify](/ru/docs/integrations/spotify) | Данные о текущем треке | OAuth + PKCE (без client secret) |
| [Streamer.bot](/ru/docs/integrations/streamerbot) | Глобальные переменные, команды чата, кастомные события для Действий | Локальный WebSocket, опциональный пароль |
| [OBS](/ru/docs/integrations/obs) | Уровни звука в реальном времени для ноды Equalizer | Локальный WebSocket, опциональный пароль |
| [Windows Media](/ru/docs/integrations/windows-media) | Данные «сейчас играет» из любого локального плеера (не только Spotify) | Не требуется — просто переключатель |

Twitch, YouTube и Spotify авторизуются через OAuth в системном браузере по умолчанию; OBScure поднимает небольшой локальный сервер для колбэков (на порту `47891`) исключительно чтобы поймать редирект от каждого провайдера после подтверждения доступа — за пределы вашего компьютера с этим сервером никто не связывается.

Streamer.bot и OBS вместо этого подключаются напрямую к WebSocket-серверу, который запускаете *вы сами* локально (собственный «Servers/Clients → WebSocket Server» в Streamer.bot, либо «Инструменты → Настройки WebSocket-сервера» в OBS) — здесь нет OAuth, только host/порт и опциональный пароль, если на той стороне включена авторизация.
