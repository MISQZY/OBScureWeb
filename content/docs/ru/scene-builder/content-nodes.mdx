# Ноды контента

Ноды контента — это то, что реально появляется на экране. Большинство из них принимают одни и те же два групповых сокета-модификатора — **Transform** (Position/Size/Transform) и **Style** (Opacity/Shadow/Animation/Hide/Overflow/Spacing) — см. [«Ноды Transform и Style»](/ru/docs/scene-builder/transform-style-nodes). Ноды с собственным выходом **Content**/**As Target** можно подключать к сокету Children контейнера или к сокету Target у Task (см. [«Ноды процесса»](/ru/docs/scene-builder/process-nodes)).

## Scene  [#scene]

Единственный итоговый узел каждой сцены — один на сцену, удалить нельзя. Отрисовывается только то, что подключено к его сокету **Content** (напрямую или через Shape/Group). У него также есть отдельные сокеты для **Background FX**, **Sound**, **Layout** (Ordering — для расстановки контента верхнего уровня), **Event** (включает показ/скрытие всей сцены) и **Timer** (как долго сцена, показанная по событию, остаётся на экране).

## Text  [#text]

Произвольный оформленный текст с поддержкой плейсхолдеров.

- **Content** — сам текст; впишите `{name}`, чтобы вставить живой плейсхолдер (`{user}`/`{amount}`/`{message}`/`{source}` от Event, собственное имя переменной от Variable, `{time}` от подключённого Clock, `{artist}`/`{title}` от подключённого Audio Player, `{number}`/`{numbers}`/`{hash}`/`{seed}` от подключённого источника Random). Кнопка-подсказка рядом с полем показывает только те плейсхолдеры, что реально доступны при текущем подключении.
- **Color**, **Font** (любой шрифт, установленный в системе, либо шрифт оверлея по умолчанию), **Size**, **Letter spacing**, **Line height**, **Align** (слева/по центру/справа), **Vertical** (сверху/по центру/снизу), **Bold**/**Italic**.
- **Outline** — толщина и цвет, по умолчанию выключено.
- **Glow** — внешнее или внутреннее свечение, цвет, прозрачность и размытие, по умолчанию выключено.

Подключение ноды **Roulette Entrants** к сокету Content ноды Text полностью *заменяет* шаблон отформатированными строками этого списка — текстовое поле становится доступно только для чтения, но все поля оформления остаются редактируемыми. Подключение выхода Content ноды **Audio Player** или источника **Random**, наоборот, *вписывается* в существующий шаблон (заполняет его плейсхолдеры), оставляя текстовое поле полностью редактируемым.

## Image  [#image]

- **Image URL** — оставьте пустым, чтобы автоматически показывать обложку текущего трека; либо подключите выход Content ноды из раздела Live Data к собственному сокету Content ноды, чтобы получить тот же результат явно (поле URL станет доступно только для чтения при подключении).
- **Upload** — копирует локальный файл в собственное записываемое хранилище приложения, так что он продолжает работать независимо от доступности внешнего URL.
- **Fit** — Cover (обрезка по заполнению, по умолчанию), Contain, Stretch, Original size, либо Repeat (тайловый фон вместо обычного изображения).
- **Radius**, **Border** (толщина/цвет).

Image также работает как **контейнер** — у неё есть собственный сокет Children, так что можно наложить подпись или бейдж (ноду Text) прямо поверх картинки, как и у Shape. По умолчанию 96×96, пока нода Size не переопределит размер.

## Video  [#video]

Короткий клип, только по URL (без загрузки файла) — укажите адрес файла, уже доступного по HTTP.

- **Video URL**, **Radius**, **Border**.
- **Loop** (по умолчанию включено), **Muted** (по умолчанию включено — браузеры, включая встроенный Browser Source OBS, блокируют автовоспроизведение со звуком; для надёжного звука используйте [ноду Sound](/ru/docs/scene-builder/live-data-nodes#sound) вместо отключения заглушения здесь).

Тоже работает как контейнер, как и Image — подключите контент к её собственному сокету Children, чтобы наложить его на клип. По умолчанию 320×180, пока нода Size не переопределит размер.

## Shape  [#shape]

Универсальный контейнер «фон + рамка» (внутри называется «Box»).

- **Background** — цвет (или градиент).
- **Shape** — Rectangle (с собственным полем Radius), Pill, Circle, Hexagon либо Diamond (последние два обрезаются по полигону; рамка при этом всё равно следует исходному прямоугольнику, а не обрезанному контуру).
- **Border** — толщина/цвет, по умолчанию выключено.

Собственного поля отступов больше нет — вместо него подключите [ноду Spacing](/ru/docs/scene-builder/transform-style-nodes#spacing) к сокету Style. Есть собственный сокет **Children** (любая нода контента, включая другой Shape или Group) и сокет **Layout** (нода [Ordering](/ru/docs/scene-builder/transform-style-nodes#ordering) для расстановки дочерних элементов в ряд/столбец).

## Group  [#group]

Те же сокеты Children/Layout/Transform/Style, что и у Shape, но без единого декоративного поля — ни фона, ни отступов, ни формы угла, ни рамки. Невидимая обёртка исключительно для перемещения, анимации или передачи группы контента в Task как единого целого — без добавления видимой карточки под ней.

## Progress Bar  [#progress-bar]

Шкала заполнения/цели без собственных встроенных данных — всё, что она показывает, приходит из подключённого:

- Сокеты **Current** / **Target** — каждый принимает одну [ноду Variable](/ru/docs/scene-builder/live-data-nodes#variable) (Integer/Float); 0, если ничего не подключено.
- Сокет **Label** — принимает одну ноду Text, отрисовывается с *её собственным* полным оформлением (цвет/шрифт/размер/выравнивание/жирный/курсив), а не просто строкой.
- Собственные поля — исключительно внешний вид шкалы: **Orientation** (горизонтальная заполняется слева направо, вертикальная — снизу вверх), **Bar color**, **Track color**, **Thickness**, **Radius**.

## Equalizer  [#equalizer]

Аудиовизуализатор в виде столбиков/волны/точек. Подключите [ноду Audio Source](/ru/docs/scene-builder/live-data-nodes#audio-source) к её сокету **Source**, чтобы указать, какое устройство захвата или вход OBS им управляет, — сам эквалайзер не несёт никакой аудио-логики, только внешний вид:

- **Style** — Bars, Wave или Dots.
- **Bars** (количество, 2–96), **Color**, **Speed**, **Intensity**, **Radius**.

По умолчанию имеет фиксированный размер 240×80, пока нода Size не переопределит его через сокет Transform. Превью в редакторе анимируется случайным образом (реальный захват звука происходит вне окна редактора) — проверяйте вживую кнопкой **«Тест»**.

## Random Pick  [#random-pick]

Маршрутизатор, а не контейнер — при каждом показе сцены выбирает ровно **один** из подключённых **Options**, выбор обновляется при каждом повторе. Принимает те же типы контента, что и Children у Shape, включая вложение другого Random Pick как одного из вариантов.

- **Custom chance** выключено (по умолчанию) — у каждого подключённого варианта равные шансы.
- **Custom chance** включено — у каждого варианта свой редактируемый вес (по умолчанию 1; 0 полностью исключает вариант), рядом отображается вычисленный процент в реальном времени.

Не имеет собственного размера/позиции — выбранный вариант сохраняет собственное подключение (Transform/Style/Target) полностью нетронутым, как если бы он был подключён напрямую.
