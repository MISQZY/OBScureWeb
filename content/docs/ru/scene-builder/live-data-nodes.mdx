# Ноды живых данных

Самодостаточные аксессуары и источники живых сигналов. Большинство подключается в собственные выделенные сокеты **Scene** или **Start**, а не в группы Transform/Style ноды контента.

## Event  [#event]

Сопоставляет реальный алерт или команду чата, чтобы запустить сцену или процесс.

- **Kind** — Alert (уведомление платформы) или Command (команда чата из общего [реестра команд](/ru/docs/actions-and-queues#commands)).
- Для Alert: **Type** (какая подключённая платформа — Twitch или YouTube; предлагаются только реально подключённые) и **Sub-type** (конкретный алерт: Twitch → `subscription`/`raid`/`follow`, YouTube → `membership`/`super-chat`).
- Для Command: выберите нужную из реестра команд.

Подключите к сокету Event у Scene для простого паттерна показ/скрытие, либо к Start для полноценного процесса. Запущенный алерт передаёт `{user}`/`{amount}`/`{message}`/`{source}` любому плейсхолдеру Text в сцене и нодам [Condition](/ru/docs/scene-builder/process-nodes#condition).

## Sound  [#sound]

Одноразовый звук алерта. Подключите к Scene (срабатывает при показе сцены) либо к Start/Task (срабатывает в этой точке процесса).

- **Sound** — встроенный пресет либо собственный загруженный файл (сохраняется независимо от ноды/сцены до удаления).
- **Volume**.

## Timer  [#timer]

Подключённая к Scene вместе с нодой Event, её **Delay (ms)** — это то, сколько сцена, показанная по событию, остаётся видимой до автоскрытия. Если к сокету Timer у Scene ничего не подключено, сцена по событию использует значение по умолчанию — 6000 мс. (То же поле задержки, но использованное внутри цепочки процесса, — это отдельная [нода Wait](/ru/docs/scene-builder/process-nodes#wait).)

## Background FX  [#background-fx]

Полноэкранный фоновый слой, подключаемый к собственному сокету **Background FX** у Start или Scene, — аксессуар уровня сцены/процесса, а не модификатор отдельного компонента.

- **Type** — None, Gradient, Pulse, Stars, Vignette (статичная радиальная тонировка к краям), Paratrooper либо Airdrop.
- **Color**, **Speed** (0.5–2.5).
- Только для **Paratrooper**/**Airdrop**: одноразовая DOM-анимация (пиксель-арт солдат, спускающийся на парашюте и убегающий, либо ящик снабжения, спускающийся на парашюте и испускающий цветной дым) вместо обычного CSS-паттерна. **Repeat** — выкл (по умолчанию) проигрывает один раз, для повтора — Play/Test; вкл повторяет по одному разу, пока сцена показана. Собственный сокет **Caption** принимает ноду Text, чтобы подписать бирку с ником (Paratrooper) или надпись на ящике (Airdrop) обычным текстом этой ноды.

## Audio Player  [#audio-player]

Живые данные «сейчас играет» из Spotify или Windows Media — собственных полей нет, только два выхода, каждый по-разному работает в зависимости от того, куда подключён:

- **Content** — подключите к сокету Content ноды Text, чтобы заполнить её плейсхолдеры `{artist}`/`{title}`, либо к сокету Content ноды Image, чтобы безусловно показывать живую обложку альбома.
- **Event** — подключите к сокету Event у Scene, чтобы сделать всю сцену непрерывно управляемой данными (видна, пока что-то играет, Timer не нужен) и активировать сценовые плейсхолдеры `{title}`/`{artist}`/обложка; и/или к сокету Event у Start, чтобы запускать процесс при каждой смене трека вместо реального алерта. Можно подключить и туда, и туда одновременно — это независимые сокеты.

## Audio Source  [#audio-source]

Задаёт, на какой аудиовход реагирует [Equalizer](/ru/docs/scene-builder/content-nodes#equalizer) — сама не несёт звука, только выбор источника:

- Переключатель **Source** — **«Микрофон/устройство»** (реальное локальное устройство захвата, анализируется непрерывно внутри самого приложения — продолжает работать, даже когда окно свёрнуто в трей) или **«Источник звука OBS»** (один из входов микшера самого OBS, читается через [интеграцию OBS](/ru/docs/integrations/obs); синтезированный псевдоспектр по громкости, а не честный частотный анализ).
- Опционально можно подключить выход Content ноды **Audio Player** к собственному (необязательному) сокету Content этой ноды вместо выбора источника — тогда Equalizer просто пульсирует во время воспроизведения, без микрофона и подключения к OBS.

## Clock  [#clock]

Живой плейсхолдер `{time}` — без собственного визуального представления. Подключите её выход **Content** к сокету Content ноды Text и используйте `{time}` в шаблоне этой Text; применяется оформление принимающей Text, здесь оформления нет.

- **Format** — произвольный текст с токенами `YYYY`, `MM`, `DD`, `HH` (24ч), `hh` (12ч), `mm`, `ss`, `A` (AM/PM); всё остальное (двоеточия, точки, подписи) выводится буквально, например `HH:mm:ss` или `DD.MM.YYYY HH:mm`.

## Variable  [#variable]

Одно именованное типизированное значение — регистрирует `{name}` как плейсхолдер шаблона, который может использовать любая Text в сцене, и (только Integer/Float) может быть подключено к сокетам Current/Target у [Progress Bar](/ru/docs/scene-builder/content-nodes#progress-bar).

- **Scope: Local** (по умолчанию) — имя и значение хранятся прямо на этой ноде.
- **Scope: Global** — имя и значение вместо этого берутся из переменной, зарегистрированной на странице [«Данные → Переменные»](/ru/docs/data#variables); та же запись потом обновляется везде, где на неё ссылаются, во всех сценах, включая уже открытый Browser Source в реальном времени.
- **Scope: Integration** — значение читается вживую из подключённой интеграции (только для чтения): числовая статистика Twitch (**followers**/**subscribers**/**viewers**) либо живая [глобальная переменная Streamer.bot](/ru/docs/integrations/streamerbot). Предлагаются только реально подключённые интеграции.
- **Type** (только для Local/Global) — String, Boolean, Integer или Float.

Строковое/булево значение, подключённое к Current/Target у Progress Bar, приводится к числу так же, как если бы вы переключили его собственный Type на Integer/Float.
