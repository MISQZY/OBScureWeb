# Ноды процесса

Ноды процесса строят **цепочку последовательности** `Start → Task → Wait → ... → End`, наложенную поверх обычного графа контента (см. [«Два независимых вида связей»](/ru/docs/scene-builder#два-независимых-вида-связей)). Используйте цепочку вместо более простого паттерна Event+Timer→Scene, когда нужен точный многошаговый тайминг — показать элемент, подождать, обновить его, подождать снова, скрыть, — а не одно плоское окно показа/скрытия.

## Start  [#start]

Точка входа. Подключите триггер к собственному сокету **Event**, чтобы выбрать, что запускает всю последовательность, — [нода Event](/ru/docs/scene-builder/live-data-nodes#event) (реальный алерт) либо собственный выход Event источника Audio Player/Roulette/Random (запускает при смене трека / начале раунда / фиксации розыгрыша вместо алерта). Нода **Sound** или **Background FX**, подключённая сюда, срабатывает один раз в самом начале. Обычный выход — это первая связь последовательности, ведущая к Task или Wait.

## Task  [#task]

Один шаг: показывает, скрывает или обновляет ровно **один** компонент.

- Сокет **Target** — Text/Image/Shape/Group/Video/Progress Bar/Roulette Widget, на который влияет этот шаг.
- **Action** — Show, Hide либо Update.
- Сокеты **Transform** / **Style** (более узкая версия обычной группировки — без Hide, поскольку видимость уже задаётся собственным Action этого шага; без Overflow/Spacing, которые применяются только на момент построения) — модификаторы, действующие *в момент срабатывания этого шага*, поверх базовых модификаторов цели.
- Сокет **Sound** — одноразовый звук для конкретно этого шага (в отличие от собственного Sound у Start, который срабатывает один раз в самом начале). Для звука нужен подключённый Target, даже для в остальном пустого шага Update, — это привязывает звук к данному моменту последовательности.

Animation, подключённая к шагу Show/Hide, проигрывается как вход/выход этого шага; на шаге Update игнорируется (Update меняет только Position/Size/Transform, не затрагивая видимость).

## Wait  [#wait]

Пауза в последовательности — задержка (мс) между предыдущим шагом и следующим. В процессе может быть сколько угодно нод Wait, у каждой своя задержка.

## Condition  [#condition]

Разветвляет последовательность надвое на основе полей сработавшего алерта — та же терминология `{user}`/`{amount}`/`{message}`/`{source}`, которую уже читает плейсхолдер Text.

- **Field** — Username, Amount, Message либо Platform.
- **Is** — оператор сравнения. Для Amount доступны числовые операторы (`=`, `≠`, `>`, `≥`, `<`, `≤`); для остальных — `=`, `≠`, `contains` (без учёта регистра).
- **Value** — выбор платформы для поля Platform, для остальных — произвольный текст.
- Выходы **Then** / **Else** — подключите следующий шаг для каждой ветки.

Имеет смысл только для процесса, запущенного реальным Event, — процесс, запущенный от Audio Player/Roulette/Random, не имеет алерта для проверки, поэтому всегда идёт по **Else**, как и при поле, которого просто нет в конкретном алерте (например, `Amount` у обычного фоллова).

## End  [#end]

Точка выхода. Достижение её (по последовательности от последнего Task/Wait) полностью сворачивает сцену — Background FX/Sound останавливаются, и каждый управляемый Task-ами компонент очищается. Собственных полей нет. Можно вообще не подключать End — тогда цепочка просто выполняется, пока не закончатся шаги.
