# Действия и очереди

Эта система построена по прямому образцу «Actions & Queues» из Streamer.bot — если вы уже пользовались Streamer.bot, устройство покажется знакомым. Она состоит из трёх частей: **команд**, **действий** и **очередей**.

## Команды  [#commands]

Общий реестр команд чата: слова-триггеры, необязательный префикс и права настраиваются **один раз**, и дальше та же команда переиспользуется по имени везде, где OBScure просит её выбрать (команда входа в Рулетку, триггер Действия).

- **Слова-триггеры** — одно или несколько слов-алиасов, каждое из которых запускает одну и ту же команду.
- **Есть префикс** / **Префикс** — например, требование ведущего `!`.
- **Кто может использовать** — Все, Фолловеры или Сабскрайберы.

Управление командами — в разделе **«Действия и очереди → Команды»**.

## Действия  [#actions]

Именованное действие запускает одну сцену из [Scene Builder](/ru/docs/scene-builder) и при каждом срабатывании попадает в одну из ваших очередей.

- **Сцена** — какую сцену запускает это действие (сначала создайте её в Scene Builder — иначе выбирать будет нечего).
- **Очередь** — в какую очередь попадает этот запуск.
- **Длительность, сек** — сколько времени очередь считает этот запуск «занимающим» её, прежде чем в блокирующей очереди начнётся следующий. Определить реальное окончание показа сцены на экране из главного процесса невозможно, поэтому это настраиваемая оценка, которую вы задаёте по фактической длительности анимации сцены, а не что-то измеряемое автоматически.
- **Команда в чате** — выберите команду из реестра, чтобы чат мог запускать это действие напрямую.
- **Запускать из Streamer.bot** — необязательный второй источник триггера, один из:
  - **Custom Event** — сопоставляется с выбранным вами **именем события**; создайте в Streamer.bot Action с саб-экшеном «Raise Event», у которого Event Name совпадает с этим именем.
  - **Команда Streamer.bot** — сопоставляется с **именем команды**, без учёта регистра, с полем Command этой команды в Streamer.bot.

Запустить действие вручную можно в любой момент кнопкой **«Запустить»**, независимо от того, сработала ли его команда в чате или триггер Streamer.bot.

## Очереди  [#queues]

Каждое действие попадает в очередь — по умолчанию одну очередь «Default», которую нельзя удалить, но можно добавлять новые и перенаправлять действия в них.

- **Блокирующая** очередь — выполняет действия по одному, каждое занимает очередь на своё настроенное время (Длительность), прежде чем начнётся следующее. Используйте для всего, что не должно визуально перекрываться (алерты, делящие одну и ту же область экрана).
- **Обычная** (неблокирующая) очередь — запускает каждый заход мгновенно при попадании в очередь, параллельно. Используйте для всего, что безопасно показывать одновременно.

Каждая очередь показывает живые счётчики **«В очереди»** и **«Выполнено»**, обновляемые в момент постановки в очередь, старта, завершения запуска или паузы/переключения очереди — **«Сбросить счётчик выполненных»** очищает счётчик, не затрагивая то, что уже в очереди. Пауза очереди останавливает запуск новых заходов (уже запущенные всё равно завершатся); блокирующая очередь на паузе всё ещё принимает новые заходы, просто не запускает их до снятия паузы.

Очередь, на которую всё ещё ссылаются действия, удалить нельзя — сначала перенаправьте их на другую очередь, — а очередь Default нельзя удалить вообще.
