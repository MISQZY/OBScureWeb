# Профили и настройки

## Профили

Полную картину см. в [«Начало работы → Профили»](/ru/docs/getting-started#профили) — профиль объединяет оверлеи, токены интеграций и настройки в один переключаемый блок, управляется из меню профиля в заголовке окна.

## Настройки

Все настройки ниже общие для приложения, а не привязаны к конкретному оверлею, и находятся в разделе **«Настройки»** боковой панели.

### Окно

- **Сворачивать в трей** — см. [«Начало работы → Сворачивание в трей»](/ru/docs/getting-started#сворачивание-в-трей) о том, что именно это делает и почему окно при этом полностью закрывается, а не просто скрывается.

### Адрес overlay-сервера  [#overlay-server-address]

Host и порт локального сервера, раздающего страницы всех оверлеев для Browser Source в OBS, — общие сразу для всех оверлеев, так что изменение здесь обновляет ссылку для OBS у каждой сцены одновременно. Расширение host за пределы `127.0.0.1` делает оверлеи доступными с других устройств в локальной сети **без какой-либо авторизации** — делайте это только если второй машине действительно нужен доступ к оверлею, и указывайте в OBS реальный IP этой машины в локальной сети вместо адреса-плейсхолдера.

### Холст  [#canvas]

Разрешение и соотношение сторон холста трансляции по умолчанию — используется только для размера превью оверлеев внутри приложения, чтобы их пропорции совпадали с тем, что реально покажет OBS. Это **не** управляет размером/позицией самого Browser Source в OBS — они настраиваются отдельно там же. Любая отдельная сцена может переопределить это значение по умолчанию своим собственным размером холста — см. [«Scene Builder → Размер холста»](/ru/docs/scene-builder#размер-холста).

### Оформление и язык

- **Цветовая тема** — светлая, тёмная или системная.
- **Язык интерфейса** — язык самого интерфейса приложения (не связан с тем, на каком языке вы читаете эту документацию).
- **Свои темы/языки** — скачайте пример конфигурационного файла, чтобы увидеть ожидаемый формат, отредактируйте и загрузите обратно, чтобы добавить свою тему или язык. Некорректный файл (без обязательного поля `mode`/`colors` или `dictionary`) отклоняется с объяснением.

### Справка

- **«Показать инструктаж заново»** — повторяет общий онбординг-тур приложения из [«Начало работы»](/ru/docs/getting-started#первый-запуск-инструктаж).
- Собственный, более подробный инструктаж Scene Builder — отдельный: откройте любую сцену и нажмите **«Инструктаж»** в её панели инструментов.
