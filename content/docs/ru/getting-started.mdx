# Начало работы

## Установка OBScure

OBScure — приложение только для Windows, собранное на `electron-vite` и упакованное через `electron-builder`. Доступно в двух вариантах:

- **NSIS-инсталлятор** — обычный установщик Windows.
- **Portable** — один `.exe`-файл без установки, запускается откуда угодно.

После установки приложение обновляется само (через `electron-updater`) и после обновления показывает окно «Что нового» со списком изменений с той версии, с которой вы обновились.

## Первый запуск: инструктаж

При первом открытии OBScure показывает инструктаж по боковой панели, статусу интеграций на дашборде и адресу overlay-сервера в настройках. Вернуться к нему можно в любой момент: **Настройки → Справка → Показать инструктаж заново**. Первое открытие сцены в Scene Builder тоже предлагает свой, более подробный инструктаж по узловому редактору — кнопка **«Инструктаж»** в панели инструментов редактора сцены повторяет его.

## Подключение оверлея к OBS

Каждый оверлей, который собирает OBScure, — это обычная веб-страница, которую раздаёт небольшой локальный HTTP/WebSocket-сервер внутри приложения. Чтобы вывести его на трансляцию:

1. Откройте раздел **«Оверлеи»** в боковой панели и выберите (или создайте) оверлей.
2. В панели инструментов редактора сцены скопируйте **ссылку для OBS** — это и есть адрес Browser Source, он обновляется автоматически при смене URL-ключа оверлея.
3. В OBS добавьте **Browser Source**, вставьте эту ссылку и укажите ширину/высоту, совпадающие с холстом (см. [«Размер холста»](/ru/docs/scene-builder#размер-холста) о том, как превью редактора соотносится с этим).
4. Соберите содержимое оверлея в Scene Builder — см. раздел [«Scene Builder»](/ru/docs/scene-builder) про сам узловой редактор и страницы справочника нод про то, что делает каждая нода.

Host и порт этого локального сервера общие для всех оверлеев текущего профиля — поменяйте их один раз в **Настройки → Адрес overlay-сервера**, и адреса всех Browser Source обновятся автоматически. Если расширить адрес прослушивания за пределы `127.0.0.1`, оверлеи станут доступны с других устройств в локальной сети без какой-либо авторизации — делайте это только если вам действительно нужно достучаться до оверлея с другого компьютера, и в OBS указывайте реальный IP этой машины вместо адреса-плейсхолдера, показанного в приложении.

## Подключение сервисов

Без хотя бы одной подключённой интеграции живых данных не будет — на Дашборде подключённые сервисы подсвечены зелёным. Откройте **«Интеграции»** в боковой панели и смотрите раздел [«Интеграции»](/ru/docs/integrations) с пошаговой настройкой Twitch, YouTube, Spotify, Streamer.bot, OBS и Windows Media — у каждой свои шаги.

## Профили

**Профиль** — это полный изолированный набор оверлеев, токенов интеграций и настроек. Можно хранить несколько профилей — например, по одному на игру или на персону стрима — и переключаться между ними из меню профиля без перезапуска приложения.

- При переключении профиля пересоздаются интеграции (Spotify/Twitch/YouTube/Windows Media) и конфигурация под новый профиль, но сам overlay-сервер продолжает работать — Browser Source в OBS не нужно переподключать, если только новый профиль не использует другие host/порт.
- У каждого профиля свой аватар (можно загрузить фото или просто выбрать цвет), чтобы их было легко различать в переключателе.
- Удаление профиля безвозвратно удаляет все его настройки — отменить это нельзя.

Управлять профилями можно из меню профиля → **«Управление профилями...»**.

## Сворачивание в трей

По умолчанию закрытие или сворачивание окна OBScure работает как обычно в Windows. Включите **«Сворачивать в трей»** в **Настройки → Окно**, чтобы изменить это: кнопки «Свернуть» и «Закрыть» будут прятать приложение в системный трей. В отличие от типичного трей-приложения, окно при этом полностью закрывается (освобождая память и процессор), а не просто скрывается — в фоне продолжают работать только overlay-сервер и подключённые интеграции, поскольку ни один из них не живёт внутри самого окна. Открыть приложение снова можно через значок в трее в любой момент.
